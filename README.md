# Core Forge

A standalone GitHub-compatible git forge in one Node process, standard library only: git smart
HTTP, the REST v3 API, GraphQL v4 and an MCP endpoint over one in-memory store.

Status: scaffold — the REST v3 resources run end to end (repositories, branches, commits,
contents, labels, issues, pull requests); the git protocol, GraphQL and MCP layers are next.
See BUILD.md for the plan and the open questions.

Run it with `node main.ts` (Node 22). MIT licensed.
